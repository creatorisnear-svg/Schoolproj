Questions

When does GTA 6 come out?

November 19, 2026, on PS5, PS5 Pro and Xbox Series X|S. Rockstar has not announced a PC version.

Does RolePlayManager work with GTA 6?

Yes. The bot and the CAD run in Discord and in the browser, not inside the game, so they work for a GTA 6 server the same way they work for a GTA 5 one.

Can I set up my server before launch?

Yes, and now is the best time. Add the bot, run /setup, and list the server in the directory with the Getting ready for GTA 6 tag, so players find it before launch day.

Is it free?

The bot is free, including the web CAD, 911 calls, verification, tickets and economy. Premium adds AI voice dispatch and removes the limits for $5 a month, and there is a free 7 day trial. See pricing.
